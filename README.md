# System-Monitor
Created a simple monitor to see system specs, processes along with their CPU and RAM usage as well as their uptime using python. 
Utilizes a GUI with 3 tabs one for System Specs, one for Process Monitoring and the third for viewing Process Uptime.
It as of now only windows compatible but will hopefully be compatible with other operating systems.

psutil install required for script to run.

4 files now each with their own purpose which run from main.py
